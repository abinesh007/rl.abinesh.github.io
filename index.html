# Jan Arogya Pusthak (JAP) - ABDM Micro-Portal

📌 Problem Space: Fragile paper logs are easily damaged or misplaced by rural patients. Existing portal solutions (like native ABHA applications) demand consistent high-bandwidth 4G networks and expensive smartphone terminals, entirely locking out over 60% of rural clinical demographics.

🚀 The Architecture Solution: JAP introduces an ultra-lightweight browser registry engineered to request patient clinical health records directly via secure Ayushman Bharat Digital Mission (ABDM) Gateway configurations.

Key Product Vectors: • Consent Flow Integration: Requests authorization securely over lightweight data packets.
• Multi-Channel Notifications: Alerts dispatched via SMS or structured WhatsApp text layouts.
• Client Registry Search: Empowers primary healthcare (PHC) clinicians to search historical logs in < 3s.

🛠️ Stack: Tailwind CSS, HTML5 Canvas integration, ES6 Modules, Cryptographic OTP Consent API protocols.

# Local Routes Confidence Layer (LRCL) - Routing Engine

📌 Problem Space: Standard routing platforms (Google Maps APIs) optimize exclusively for shortest geographical paths or broad vehicular traffic averages. In densely populated, developing cities, this sends standard cars down extremely narrow pathways (width < 3m) or bustling local bazaars, causing catastrophic bottlenecks and vehicle damage.

🚀 The Algorithmic Solution: A layered middleware protocol that injects a mathematical "Confidence Coefficient" (C) directly onto active routing vectors. If a narrow municipal road drops below safety thresholds, standard GPS directions immediately route larger vehicles away.

Algorithmic Formulation: Confidence Score Formula:
C = Width_Coeff * 10 - Ped_Density_Factor - Vendor_Risk_Weight

🛠️ Stack: Google Maps JS API framework overrides, Python optimization scripts, GIS routing databases, municipal data hooks.
